Voice Signal TTS 0.2.0

Connected speech is now available in all four voices: US English, Mexican
Spanish, Canadian French, and Brazilian Portuguese. Turn off "Pause between
words" in NVDA Speech settings to use it. The default retains the original
word pauses; initial and punctuation boundaries are preserved.

New controls:
- Pause between words: choose original or connected delivery.
- Rate boost: double the native speed multiplier, within the engine limit.
- Engine gain: seven native attenuation steps. 100 retains the original level;
  0 is the lowest engine gain, not mute. Use Volume to mute.

Existing rate, pitch, volume, nvwave playback and saved settings remain.
All controls are available in Speech settings and the synth settings ring.

Install voiceSignalTTS-0.2.0.nvda-addon and restart NVDA.
Requires 64-bit Windows and NVDA 2026.1 or later.

Validation: real engine checks passed for all four languages, punctuation
boundaries, gain and rate boost. Automated driver integration checks passed.
The user confirmed connected speech works in live NVDA in all four languages.
